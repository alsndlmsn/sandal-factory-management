# سجل الاختبار المرحلي — نظام مصنع الصندل

هذا السجل يوضح ما تم اختباره دون إنشاء بيانات إنتاج وهمية أو تنفيذ حركات مالية حقيقية.

## الواجهة الأساسية

نجح تسجيل الدخول بحساب المدير الموجود، وتحميل لوحة المدير، وظهور اسم المصنع واسم المدير والقوائم العربية RTL. نجح فتح دليل التشغيل وجميع المسارات الأساسية، مع إبقاء النوافذ المنبثقة داخل مساحة آمنة وعدم ظهور overflow أفقي في الفحص المكتبي الحالي.

## المنتجات

ظهرت قائمة المنتجات والبحث بالاسم ونموذج الإضافة والتعديل والتفاصيل والتفعيل أو التعطيل. يدعم النموذج التصنيف والوحدة الحرة والحقول المخصصة عند الطلب. نجح فتح نموذج المنتج وإضافة حقل مخصص وإغلاق النافذة دون حفظ منتج تجريبي.

## نقطة البيع والمبيعات

ظهرت قائمة الفواتير ونموذج البيع النهائي والمبدئي والمفتوح، والعميل والمخزن والخصم والمصنعية والضريبة والدفع الجزئي واختيار الخزنة أو البنك. يدعم النموذج عدة بنود، ويجمع المنتج المكرر في سطر قائم بدل إنشاء سطر جديد. أضيف اعتماد الفاتورة ودالة دفعة لاحقة تقفل الفاتورة وتحدّث المتبقي والحساب المالي وتمنع التكرار. صُحح حفظ معرّف البنك وحالة الدفع النهائي عبر البنك. نجح تحميل القائمة وفتح النموذج دون إنشاء فاتورة حقيقية. أضيفت طباعة فاتورة مختصرة ورابط مشاركة واتساب من قائمة الفواتير، مع إخفاء تكلفة المنتج عن مستند العميل، ونجح فتح النموذج بعد الإضافة.

## المخزون والمخازن

ظهرت إدارة المخازن بأنواع الخام والجاهز والتالف، وسجل حركات الوارد والصادر والتحويل، مع إبقاء الرصيد معتمدًا على الحركات المعتمدة فقط. أضيف اعتماد الحركة وتحديث الرصيد، ونجح فتح نموذج مخزن جديد دون حفظ.

## الخزائن والبنوك والمالية

ظهرت نماذج إنشاء الخزنة والبنك والمصروف مع ربط الدفع بالحساب. أضيف اعتماد المصروف بحيث لا يخرج المال قبل الاعتماد. أضيف التحويل الداخلي بين الخزائن والبنوك بوارد وصادر متقابلين لا يُحسبان إيرادًا أو مصروفًا، وأضيف جرد الخزنة مع الرصيد الدفتري والفرق والسبب. نجح تحميل الشاشة وفتح نموذج التحويل دون تنفيذ حركة مالية.

## الموردون والمشتريات والخامات

ظهرت إدارة الموردين والخامات وشراء متعدد البنود، مع ترحيل الاعتماد إلى مخزون الخام وربط الدفع بالخزنة أو البنك ومنع اعتماد فاتورة الشراء مرتين. نجح تحميل القسم وظهور النماذج دون حفظ عملية شراء حقيقية.

## الإنتاج

توافق RPC الإنتاج مع مخطط أوامر الإنتاج الفعلي. أضيف اعتماد الناتج مع اشتراط تطابق الإنتاج الفعلي مع المقبول والتالف، وإدخال المقبول إلى مخزن المنتجات الجاهزة وتسجيل التالف في جدول مستقل ومنع الاعتماد المتكرر. نجح تحميل شاشة الإنتاج وظهور مسار أمر الإنتاج والاعتماد.

## المرتجعات والتالف

يبدأ نموذج المرتجع من فاتورة معتمدة وبند أصلي، ويقسم الكمية إلى صالح وتالف وتحت الفحص. رُبط الاعتماد بحركة المخزون وسجل التالف والرد المالي ومنع تجاوز الكمية أو تكرار الاعتماد. أضيف توزيع الرد المالي على دفعات الفاتورة الفعلية مع سجل return_refunds، والتحقق من مجموع الصالح والتالف والفحص وحد الكمية. نجح فتح النموذج دون إنشاء مرتجع.

## الموظفون والحضور والمرتبات

ظهرت إضافة العامل مع القسم والوظيفة والوردية ونوع الأجر والراتب، والحضور والانصراف بزر يسجل الزمن تلقائيًا. أضيف تعديل ملف العامل وتغيير حالته إلى نشط أو موقوف أو إجازة أو مؤرشف دون حذف تاريخه. أضيفت السلف المرتبطة بالخزنة أو البنك والحوافز وفترات المرتبات، وصُحح توزيع خصم السلف على السلف الفعلية، وأضيف دفع كشف المرتب من الخزنة أو البنك. نجح تحميل الأقسام وفتح نماذجها دون حفظ بيانات حقيقية.

## المستخدمون والأدوار وسجل التدقيق

تم نشر Edge Function إدارية تتحقق من جلسة المدير، ولا تضع مفتاح الخدمة أو كلمة المرور في الواجهة، وتستخدم أعمدة profiles وuser_roles الفعلية. نجح تحميل دليل المستخدمين وفتح نموذج إنشاء حساب دون إنشاء مستخدم. أضيفت ضوابط الأدوار لنطاق البيانات وإظهار الحسابات المالية ووارد وصادر وتحويل وجرد واعتماد وحدود الصرف والخصم والتحويل والتسوية، ونجح فتح نموذجها. يعرض سجل التدقيق المنفذ والقسم ورقم السجل والقيم قبل وبعد والسبب عند وجوده.

## الإعدادات وPWA

أصبح اسم المصنع والعملة ونسبة الضريبة تحفظ مركزيًا في جدول settings عبر RPC للمدير، مع نسخة محلية مساعدة. تغيير كلمة المرور يستعمل Supabase Auth داخل الجلسة. أضيف manifest وservice worker، وتحقق المتصفح من سيطرة service worker على الصفحة المحلية.

## الأمان والموارد

استبدلت سياسات الوصول المفتوحة بسياسات قراءة وكتابة مرتبطة بالصلاحيات والمدير، ثم نجحت إعادة تحميل لوحة المدير والتقارير والتدقيق والمخزون والموردين والمرتجعات والإنتاج والمرتبات بعد RLS. نجحت فحوص صياغة JavaScript و`git diff --check`، وتأكد تقديم index وmanifest وservice worker وCSS وملفات JavaScript محليًا بحالة HTTP 200. لم تُنفذ عمليات مالية أو سجلات إنتاج وهمية.

## ملاحظات ما بعد النشر

لم تُنفذ عمليات mutation أو سجلات إنتاج وهمية لأن ذلك يغيّر بيانات المصنع. يمكن إجراء اختبار إدخال مضبوط لاحقًا ببيانات يوافق عليها صاحب المصنع ثم تنظيفها ضمن معاملة آمنة. كما يُستحسن إكمال اختبار مقاسات الهاتف الفعلية على أجهزة مختلفة وتوسيع قوالب التقارير المطبوعة عند الحاجة. النسخة الحالية نُقلت إلى `main`، وحالة GitHub Pages أصبحت `built`، وظهر عنوان النظام الجديد في الرابط العام: https://alsndlmsn.github.io/sandal-factory-management/ .
