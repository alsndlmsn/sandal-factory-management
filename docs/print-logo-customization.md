# تخصيص قالب الطباعة بشعار المصنع

## الوضع الحالي

قالب الطباعة يدعم شعارًا اختياريًا. عند عدم وجود شعار، تظهر علامة `SP` تلقائيًا حتى تستمر الفاتورة والتقارير في العمل. لم يتم وضع شعار تجريبي أو اختراع شعار حقيقي للمصنع.

## الطريقة الموصى بها: اختيار ملف من واجهة المدير

المسار الجديد لا يحتاج إلى تعديل `config.js` أو نسخ رابط يدويًا. سجّل الدخول بحساب المدير، افتح **الإعدادات ← هوية المصنع**، ثم اضغط **اختيار ملف** داخل بطاقة الشعار. يقبل النظام ملفات PNG وJPG وWEBP وSVG حتى 2MB، ويعرض معاينة فورية قبل تثبيت الإعداد.

عند اختيار الملف، ترفعه الواجهة إلى bucket عام اسمه `factory-logos` في Supabase Storage باسم ثابت `factory-logo`. بعد نجاح الرفع، يضع النظام الرابط العام في نموذج الإعدادات. اضغط **حفظ بيانات المصنع** حتى يُحفظ الرابط في سجل إعدادات المصنع عبر RPC `save_factory_settings`. بعد ذلك يستطيع الموظفون طباعة الفواتير والتقارير بالشعار نفسه دون أن يملكوا صلاحية رفعه أو تغييره.

| الخطوة | الإجراء | النتيجة المتوقعة |
|---|---|---|
| 1 | افتح الإعدادات بحساب المدير | تظهر بطاقة هوية المصنع وحقل الشعار |
| 2 | اضغط «اختيار ملف» واختر صورة ≤ 2MB | تظهر معاينة ويُرفع الملف إلى Storage |
| 3 | اضغط «حفظ بيانات المصنع» | يُحفظ رابط الشعار داخل إعدادات Supabase |
| 4 | افتح فاتورة أو تقريرًا واضغط الطباعة | يظهر الشعار في رأس النسخة الورقية |
| 5 | اضغط «إزالة الشعار» ثم احفظ | يُفرغ الإعداد ويحذف الملف من Storage |

## البديل: رابط محلي أو رابط https

يمكن بدل رفع الملف إدخال مسار محلي مثل `./assets/factory-logo.png` أو رابط `https://` موثوق في حقل الرابط أسفل بطاقة الرفع. يقبل النظام أيضًا المسارات `/` و`../`، ويرفض القيم غير المسموحة مثل `javascript:`. اترك الحقل فارغًا إذا أردت استخدام علامة `SP` البديلة.

## إعداد Storage في Supabase

أنشأت migration `052_factory_logo_storage.sql` bucket باسم `factory-logos` بحد أقصى 2MB وبأنواع الصور الأربعة. القراءة عامة لأن GitHub Pages يحتاج إلى تحميل الصورة أثناء الطباعة، بينما الرفع والاستبدال والحذف مقيدة بدور المدير المصادق عليه عبر سياسات `storage.objects`. لا تُخزن مفاتيح سرية داخل الصفحة، ولا تضع أي ملف غير مخصص للشعار في هذا bucket.

## المعاينة المحلية السريعة

للمعاينة في حساب المدير يمكن وضع المسار في إعدادات المتصفح المحلية فقط:

```js
localStorage.setItem('sandal_factory_settings_v1', JSON.stringify({
  factoryLogo:'./assets/factory-logo.png'
}));
```

بعد ذلك أعد تحميل النظام وافتح الطباعة. احذف قيمة المعاينة بعد الانتهاء إذا لم تكن تريد حفظها محليًا:

```js
localStorage.removeItem('sandal_factory_settings_v1');
```

لا تستخدم هذه الأوامر داخل الإنتاج إلا بعد التأكد من المسار. الإعداد الحالي في `config.js` فارغ عمدًا إلى أن يرسل صاحب المصنع الشعار المعتمد.

## قواعد الأمان والجودة

لا تستخدم رابطًا يبدأ بـ`javascript:` أو ملفًا غير معروف المصدر. الكود يقبل فقط مسارات محلية شائعة أو روابط `http/https`، ويهرب قيمة الرابط قبل وضعها داخل HTML. لا تضع الشعار أو مساره داخل أي مفتاح سري، ولا تستخدم خدمة تخزين خاصة إذا كانت الصفحة العامة تحتاج إلى تحميله.

اختبر أربع حالات: شعار مربع، شعار أفقي، مسار غير موجود، وعدم وجود إعداد. يجب أن تنجح الطباعة في الحالات الأربع، وأن تظهر علامة `SP` عند فشل التحميل أو غياب الشعار. تم تنفيذ مسار المدير في migration `049_factory_logo_settings.sql`، مع إزالة التوقيع القديم في `050_remove_legacy_factory_settings_signature.sql` وسحب التنفيذ العام في `051_revoke_public_factory_logo_save.sql`. تحققت قاعدة البيانات من وجود توقيع حفظ واحد فقط، وأن `anon_execute=false` و`authenticated_execute=true` لدالتي القراءة والحفظ. لا يزال التخزين الحالي يعتمد على رابط؛ إذا أردت رفع الصورة من زر «اختيار ملف» بدل إدخال رابط، نضيف لاحقًا Supabase Storage مع bucket عام أو روابط موقعة وسياسة RLS منفصلة.


## نتيجة التحقق الفني

تم اختبار قالب الطباعة ببيئة DOM مصغرة: ظهر عنصر الصورة عند استخدام `https://example.com/logo.png`، وعاد القالب إلى `SP` عند تجربة قيمة غير مسموحة تبدأ بـ`javascript:`، من دون إدخال الرابط غير الآمن إلى HTML. هذا اختبار قبول للمنطق الوقائي، وليس إثباتًا لتحميل شعار مصنع حقيقي قبل توفير ملف الشعار المعتمد.
