# نتائج اختبار نظام الإرشاد داخل التطبيق

## التاريخ
25 أغسطس 2026.

## نطاق الاختبار
تم اختبار النسخة المحلية من تطبيق مصنع الصندل بعد إضافة `js/guidance.js` وربطه في `index.html`. الاختبار عزل بيانات Supabase واستخدم محاكاة مستخدم مسجل، ولم ينفذ كتابة أو حذفًا في قاعدة البيانات.

## النتائج

| الاختبار | النتيجة |
| --- | --- |
| صفحة تسجيل الدخول | ظهرت دون زر مساعدة أو onboarding قبل المصادقة، حتى لا تربك المستخدم قبل دخوله. |
| مركز المساعدة | فتح بنجاح عبر الدالة العامة `GuidanceEngine.open()`. |
| دليل الصفحة | ظهر عنوان الصفحة والغرض والخطوة الأولى والقواعد والأخطاء الشائعة وما بعد الإكمال. |
| البحث | أعاد 7 نتائج عند البحث عن «فاتورة» ضمن الصفحات والخطوات والأخطاء. |
| تفضيلات الإرشاد | ظهرت خيارات المستوى والتلميحات والجولات وحُفظت محليًا مع بقاء المساعدة اليدوية. |
| الجولة التفاعلية | أنشأت طبقة إرشاد وركّزت على عنصر حقيقي في الصفحة مع الخطوة التالية والتخطي. |
| وضع «ما هذا؟» | عرض شرحًا لعنصر حقيقي بعد تفعيله، ويمكن إيقافه أو إغلاق الشرح. |
| التحقق قبل الإرسال | يمنع إرسال النماذج غير المكتملة، يركز على أول حقل ناقص، ويعرض رسالة تصحيح تعليمية. |
| الأوفلاين | يعرض داخل لوحة المساعدة حالة «أوفلاين · الإرشاد متاح» مع شرح أن العمليات الحساسة تنتظر المزامنة. |
| الصياغة | `node --check js/guidance.js` و`node --check js/app.js` و`node --check sw.js` نجحت. |

## الملاحظات

تم بناء الإرشاد على بيانات الصفحات الحقيقية للنظام، وليس على لقطات أو وظائف وهمية. الجولات تستخدم محددات عناصر فعلية وتُسقط الخطوات غير الموجودة بدل عرض تعليمات مضللة. أما الصلاحيات فتظل محكومة بالنظام الأصلي؛ محرك الإرشاد لا يضيف صلاحيات ولا يعرض شرحًا لقسم غير ظاهر للمستخدم.


## إعادة اختبار بعد التحسينات

بعد تعديل رسالة التحقق وإضافة اختصار لوحة المفاتيح `?` وتحسين تركيز بطاقة الجولة، أُعيد فتح صفحة الدخول المحلية. ظهرت صفحة الدخول بشكل صحيح، ولم تظهر عناصر المساعدة أو onboarding قبل المصادقة، بينما ظل `GuidanceEngine` محمّلًا بلا أخطاء. هذا يمنع إرباك المستخدم قبل تسجيل الدخول ويحافظ على المساعدة داخل النظام بعد المصادقة.
