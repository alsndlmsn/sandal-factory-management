# مخطط نظام مصنع الصندل للأوعية البلاستيكية

## 1. نطاق النظام

يُبنى النظام حول دورة العمل اليومية للمصنع: تسجيل الموظفين والحضور والورديات، متابعة المواد الخام والمنتجات النهائية، تسجيل الإنتاج، المبيعات، الصادر والوارد، المنصرفات، الخزنة والبنوك، السلفيات والمرتبات، ثم التقارير والطباعة وسجل النشاط. الواجهة عربية RTL، وتعرض لكل مستخدم ما يحتاجه فقط.

## 2. مخطط قاعدة البيانات المقترح

| المجال | الجداول الأساسية | الغرض |
|---|---|---|
| الهوية والصلاحيات | `profiles`, `roles`, `permissions`, `user_roles`, `role_permissions` | المصادقة، الأدوار، والصلاحيات المرنة القابلة للتعديل |
| إعدادات المصنع | `settings`, `departments`, `job_titles`, `shifts` | بيانات المصنع والأقسام والوظائف والورديات |
| الموظفون | `employees`, `employee_history` | ملف الموظف، الرقم التلقائي، التغييرات المؤرخة |
| الحضور | `attendance_records`, `attendance_corrections` | الحضور والانصراف والساعات والعمل الليلي والتصحيحات |
| المنتجات | `product_categories`, `units`, `products` | المواد الخام والمنتجات النهائية والأصناف والوحدات |
| المخازن | `warehouses`, `stock_movements`, `stock_movement_lines` | حركات الوارد والصادر ورصيد المخزون المحسوب |
| الإنتاج | `production_orders`, `production_materials`, `production_outputs` | أمر الإنتاج والمواد المصروفة والمنتج المقبول والتالف |
| العملاء | `customers` | بيانات العملاء المرتبطة بالمبيعات |
| المبيعات | `sales`, `sale_items` | الفواتير والدفع النقدي أو البنكي وبنود البيع |
| المالية | `cash_registers`, `cash_transactions`, `banks`, `bank_transactions` | الخزنة والبنوك وحركة القبض والصرف والتحويل |
| المصروفات | `expense_categories`, `expenses` | المنصرفات وتصنيفاتها وأقسامها وطريقة دفعها |
| المرتبات | `payroll_periods`, `payroll_records`, `payroll_items` | احتساب الراتب والبدلات والإضافي والخصومات والصافي |
| السلفيات | `employee_advances`, `advance_deductions` | السلف وحالتها والخصم الكلي أو الجزئي عبر المرتبات |
| التدقيق | `activity_logs` | من أنشأ أو عدّل أو اعتمد أو ألغى كل عملية |

## 3. العلاقات الرئيسية

```text
profiles ──< user_roles >── roles ──< role_permissions >── permissions
employees ──< attendance_records >── shifts
employees ──< employee_advances ──< advance_deductions
employees ──< payroll_items >── payroll_records >── payroll_periods
products >── product_categories
products >── units
warehouses ──< stock_movements ──< stock_movement_lines >── products
production_orders ──< production_materials >── products
production_orders ──< production_outputs >── products
customers ──< sales ──< sale_items >── products
cash_registers ──< cash_transactions
banks ──< bank_transactions
expense_categories ──< expenses
activity_logs ──> profiles
```

كل جدول تشغيلي يحتوي على `id`, `created_at`, `updated_at` عند الحاجة، ومرجع المستخدم المنشئ. الحركات المالية والمخزنية لا تُعدّل الأرصدة مباشرة؛ الرصيد يُحسب من الحركات المعتمدة فقط. السجلات التي ترتبط بتاريخ مالي لا تُحذف حذفًا نهائيًا بعد اعتمادها، بل تُلغى أو تُؤرشف مع سبب وتسجيل في `activity_logs`.

## 4. مصفوفة الأدوار والصلاحيات

| المجال / الدور | المدير | الحسابات والخزنة والمرتبات | المبيعات | المخزن | الإنتاج |
|---|---:|---:|---:|---:|---:|
| لوحة المؤشرات الخاصة بالدور | كامل | نعم | نعم | نعم | نعم |
| إدارة المستخدمين والأدوار | كامل | لا | لا | لا | لا |
| الموظفون وملفاتهم | كامل | عرض متعلق بالمرتبات | لا | لا | لا |
| الحضور والورديات | كامل | إنشاء/تعديل حسب الصلاحية | لا | لا | عرض عند الحاجة |
| المرتبات والسلفيات | كامل | كامل | لا | لا | لا |
| المصروفات | كامل | إنشاء ومراجعة واعتماد | لا | لا | لا |
| الخزنة والبنوك | كامل | كامل | عرض طريقة الدفع فقط | لا | لا |
| المنتجات والأصناف | كامل | عرض | عرض المنتجات المتاحة | كامل | عرض |
| المخزون والصادر والوارد | كامل | عرض | لا يعدّل الرصيد | كامل | طلب صرف/استلام فقط |
| الإنتاج | كامل | عرض | لا | عرض المواد | كامل |
| المبيعات والعملاء | كامل | عرض مالي | كامل | لا | لا |
| التقارير | كامل | المالية والمرتبات | المبيعات | المخزون | الإنتاج |
| الطباعة | كامل | المسموح للدور | الفواتير | تقارير المخزن | تقارير الإنتاج |
| سجل النشاط | كامل | لا | لا | لا | لا |

يُنفّذ كل إذن كصلاحية مستقلة مثل `sales.view`, `sales.create`, `sales.approve`, `inventory.view`, `inventory.create`, `inventory.approve`, `production.view`, `production.create`, `production.approve`, `employees.view`, `employees.manage`, `attendance.create`, `attendance.correct`, `payroll.view`, `payroll.calculate`, `payroll.approve`, `cash.view`, `cash.create`, `expenses.create`, `expenses.approve`, `reports.view`, و`users.manage`. تُفرض الصلاحيات في RLS ودوال PostgreSQL الآمنة، وليس في الواجهة فقط.

## 5. هيكل الصفحات المبسط

### الشاشة الرئيسية

تُظهر للمستخدم بطاقات اليوم المناسبة لدوره: مبيعات اليوم، رصيد الخزنة، المنصرفات، الحضور، الإنتاج، تنبيهات المخزن، وصافي النتيجة. أسفلها أزرار مباشرة مثل «تسجيل بيع»، «تسجيل وارد»، «تسجيل منصرف»، «تسجيل حضور»، و«تسجيل سلفية».

### الصفحات الأساسية

1. **المبيعات:** فاتورة قصيرة بخطوات اختيار العميل، الصنف، الكمية، الدفع، والمراجعة والطباعة.
2. **المخزن:** رصيد الأصناف، تسجيل الوارد، تسجيل الصادر، المواد المصروفة للإنتاج، والتنبيهات.
3. **الإنتاج:** أمر إنتاج، الوردية، المنتج، الكمية المخططة، المقبولة، والتالفة.
4. **الموظفون:** قائمة وبحث وملف موظف يتضمن البيانات والحضور والسلفيات والمرتبات.
5. **الحضور:** اختيار الموظف، حضور أو انصراف، الوردية، الساعات، والتنبيه عن الانصراف المفقود.
6. **المرتبات:** الفترة، الحساب، السلفيات والخصومات، المراجعة، الاعتماد، الدفع، وطباعة القسيمة.
7. **المنصرفات والخزنة:** نموذج مختصر، تصنيف واضح، طريقة الدفع، ومرجع البنك عند الحاجة.
8. **التقارير:** تقارير حسب الدور والفترة مع بحث وفرز وطباعة وتصدير عملي.
9. **الإدارة:** المستخدمون، الأدوار، الصلاحيات، إعدادات المصنع، وسجل النشاط، للمدير فقط.

## 6. خطة التنفيذ

| المرحلة | الناتج |
|---|---|
| 1 | أرشفة النسخة القديمة وتنظيف المستودع، ثم إعداد المشروع والاتصال والمصادقة |
| 2 | قاعدة البيانات الجديدة والعلاقات والفهارس وRLS والصلاحيات المرنة |
| 3 | الموظفون والأقسام والوظائف والرقم التلقائي والحضور والورديات |
| 4 | المنتجات والمخزون وحركات الوارد والصادر وتنبيهات الحد الأدنى |
| 5 | الإنتاج وصرف المواد واستلام المنتج النهائي والتالف |
| 6 | المبيعات والعملاء والدفع النقدي والبنكي والتحديث التلقائي للمخزون والخزنة |
| 7 | المنصرفات والخزنة والبنوك والسلفيات والمرتبات والخصومات |
| 8 | التقارير والطباعة وسجل النشاط واختبارات RLS والاستجابة والنشر |

لا تُستخدم بيانات وهمية داخل قاعدة بيانات العميل. للاختبار، تُستخدم سجلات مؤقتة معلّمة بوضوح أو بيانات يضيفها المستخدم من شاشة الإعداد، ثم تُحذف أو تُؤرشف وفق قواعد السجل المالي.
