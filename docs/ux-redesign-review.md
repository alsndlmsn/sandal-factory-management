# مراجعة إعادة تصميم تجربة المستخدم

تمت مراجعة النسخة المحلية بعد إعادة بناء الهوية البصرية. شاشة الدخول أصبحت بوابة واضحة مقسومة إلى تعريف بالمصنع ونموذج دخول مستقل، مع عنوان «كل عمليات المصنع، في مكان واحد».

بعد الدخول يظهر شريط جانبي مصنف إلى الرئيسية، الإدارة، التشغيل، المالية، والمتابعة. تظهر للمدير الأقسام: لوحة التحكم، دليل التشغيل، المستخدمون، الأدوار والصلاحيات، الموظفون والوظائف، الحضور والورديات، المنتجات، المخزن والوارد والصادر، الإنتاج، المبيعات والعملاء، المصروفات، الخزنة والبنوك، المرتبات والسلفيات، التقارير والطباعة، سجل التدقيق، وإعدادات المصنع.

تمت إضافة «دليل التشغيل» يشرح أين يسجل المستخدم العامل ووظيفته، الحضور، الإنتاج، المبيعات، المخزن، المصروفات، السلفيات، الخزنة والبنوك، والمستخدمين والصلاحيات. صفحة الموظفين تعرض زر «موظف جديد» ونموذجًا يحتوي اسم العامل، الهاتف، القسم، الوظيفة، نوع الأجر، والأجر الأساسي. يتم إنشاء علاقة القسم والوظيفة عند الحفظ بدل تركها نصًا غير مرتبط.

تمت إضافة نوافذ عمليات للمبيعات والمخزن والإنتاج والمصروفات والخزنة والسلفيات والمنتجات، مع حالات مسودة واعتماد في النصوص. ما زال الاختبار المطلوب قبل النشر العام هو فتح كل نافذة والتأكد من توافق حقولها مع قيود Supabase، ثم نشر الإصدار الجديد.
