# مخطط نظام مصنع الصندل للأوعية البلاستيكية

## الهدف

نظام ويب عربي حديث لإدارة المصنع من المنتجات والمبيعات والمرتجعات والتالف والموردين والمشتريات والمواد الخام والإنتاج والمخزون إلى الخزائن والبنوك والمصروفات والمرتبات والمستخدمين والصلاحيات والتقارير. كل عملية لها مستخدم وتاريخ ووقت وحالة، وكل أثر مالي أو مخزني ينشأ من عملية معتمدة ولا يسمح بالتعديل العشوائي للأرصدة.

## الوحدات

| الوحدة | البيانات الرئيسية | الأثر المرتبط |
|---|---|---|
| المنتجات | الاسم، التصنيف، الوحدة، التكلفة، البيع، الحد الأدنى، الحقول المخصصة | تظهر في البيع والمخزون والإنتاج والمرتجعات |
| المبيعات | بيع، مبدئية، مفتوحة، بنود، خصم، مصنعية، ضريبة، دفعات | خصم المخزون وإضافة المال للخزنة أو البنك بعد الاعتماد |
| المرتجعات | فاتورة أصلية، بنود، حالات صالح/فحص/تالف، استرداد | إعادة الصالح للمخزون وإضافة التالف لسجله وعكس المال عند الاسترداد |
| التالف | المصدر والحالة والإجراء | لا يظهر في المتاح للبيع، ويرتبط بالإنتاج أو التدوير أو الإتلاف |
| الموردون والمشتريات | مورد، شراء متعدد البنود، دفعات، متبقي | زيادة مخزون الخام وخفض الخزنة/البنك أو تسجيل التزام |
| المواد الخام | اسم وكود ووحدة وسجل حركة | تصرف للإنتاج وتظهر تكلفتها ضمن تكلفة التشغيل |
| الإنتاج | أمر، نوع، خام مستخدم، ناتج، تالف، وجهة | صرف خام وإضافة المنتج الناتج إلى موقع مخزني |
| المخزون | مواقع، وارد، صادر، تحويل، جرد، رصيد | الرصيد يحسب من الحركات المعتمدة فقط |
| الخزائن والبنوك | حسابات، حركات، تحويلات، توريدات، تسويات | دفتر مالي مركزي ورصيد محسوب من الحركات |
| الموظفون والمرتبات | عامل، حضور، سلف، حوافز، كشف، دفع | خصم السلف وإضافة الحوافز وربط الدفع بخزنة أو بنك |
| المستخدمون والصلاحيات | حساب، دور، صلاحيات، حدود، مستوى رؤية | حماية كل شاشة وعملية وتسجيل المنفذ |
| التقارير والتدقيق | مؤشرات وفلاتر وطباعة وتصدير | قراءة موحدة من العمليات المعتمدة وسجل النشاط |

## قواعد الحساب والربط

تُحسب مبيعات اليوم من الفواتير المعتمدة فقط. الربح الإجمالي يساوي قيمة البيع بعد الخصم والمصنعية والضريبة بحسب إعداد الضريبة، مطروحًا منه تكلفة البنود المباعة. الربح بعد المصروفات يطرح المصروفات المعتمدة من الربح الإجمالي. ضريبة القيمة المضافة تظهر باسمها الصحيح، وتكون قابلة للتفعيل مع نسبة من الإعدادات.

الرصيد المخزني يساوي الرصيد الافتتاحي زائد الوارد والإنتاج والمرتجع الصالح والتحويل الوارد، ناقص المبيعات والصادر والتحويل الصادر. لا يسمح النظام بصرف أكبر من المتاح، ولا يخصم البيع مرتين عند إعادة المحاولة أو عند دفع متبقٍ على نفس الفاتورة.

الرصيد المالي لكل خزنة أو بنك يساوي الرصيد الافتتاحي زائد الوارد والدفعات الداخلة والتحويلات الواردة، ناقص المصروفات والمرتبات والسلف ومدفوعات الموردين والاستردادات والتحويلات الخارجة. التحويل بين خزنة وبنك أو بين خزنتين تحويل داخلي وليس إيرادًا أو مصروفًا.

## دورة الحالات

كل عملية تمر غالبًا بمسودة، ثم مراجعة، ثم اعتماد، ثم تنفيذ، ويمكن أن تصبح مدفوعة جزئيًا أو مدفوعة بالكامل أو ملغاة أو مسواة أو مغلقة. لا تحذف العملية المالية أو المخزنية المعتمدة؛ يُنشأ إلغاء عكسي بسبب واضح ويحفظ الأصل.

## الأوفلاين

تعمل الواجهة بعد تحميلها على الجهاز مع البيانات الأخيرة المحفوظة محليًا. يمكن تجهيز المسودات غير الحساسة دون اتصال، وتُحفظ كل مسودة بمعرف محلي فريد. لا يتم اعتماد أو دفع أو تغيير رصيد أو تغيير صلاحية أو إعادة ضبط دون اتصال. عند عودة الشبكة تُرسل العمليات بترتيبها، ويعيد الخادم التحقق من الصلاحية والرصيد ومفتاح منع التكرار قبل التنفيذ.

## الأمن

لا توجد مفاتيح سرية في الواجهة. يستخدم المتصفح مفتاح Supabase العام فقط، وتنفذ العمليات الحساسة عبر سياسات RLS ودوال PostgreSQL محمية. المدير هو صاحب الإدارة الكاملة، ويمكنه منح صلاحيات مستقلة لكل قسم وخزنة وبنك وحد مالي ومستوى رؤية. كلمات المرور لا تظهر ولا تحفظ كنص واضح، وتغييرها يتم من جلسة مصادق عليها.

## الهوية

اسم المصنع: **مصنع الصندل للأوعية البلاستيكية**. اسم المدير: **عصام الجبل**. البريد الإداري محفوظ في حساب المصادقة، وتوجد شاشة داخلية لتغيير الاسم وكلمة المرور دون وضع بيانات السر داخل الملفات أو المستودع.

## ترتيب التنفيذ

يبدأ التنفيذ بمخطط البيانات والدوال الذرية والتدقيق، ثم طبقة الاتصال والمزامنة، ثم الواجهة العربية المتجاوبة، ثم كل النماذج والتقارير، وأخيرًا الاختبارات المتصلة وغير المتصلة واختبارات الصلاحيات وعدم تكرار الأثر المالي والمخزني.
